# AI 会话归档

本目录保存与毕设糖基化分析系统直接相关的 AI 编程会话。它记录工具使用过程，不是进度报告、周视频或本人日志总结的替代品。

## 目录约定

每个日期使用一个目录。

```text
agent-sessions/
└─ YYYY-MM-DD/
   ├─ README.md
   ├─ codex-<topic>.md
   └─ assets/
```

`README.md` 写会话工具、项目、日期、参与者、导出方式和脱敏说明。每个会话文件写清主题和对应 commit 或产物。

## 允许归档

- 与 `D:\wbworkspace\glyco-analysis` 直接相关的需求、排查、实现和验证会话。
- 能说明当时依据的日志摘录、命令和工具结果。
- 模型标识、服务类型和可公开的运行参数。

## 禁止归档

- 其他课程、私人项目或与毕设无关的聊天。
- API key、access token、Cookie、密码、私钥或完整环境变量。
- 原始数据、模型权重和超过仓库需要的大体积附件。
- 未经检查的完整终端历史。

## 导出流程

1. 用 AgentsView、Cursor、Claude Code 或 Codex 自带导出按项目筛选。
2. 只保留本项目会话，删除其他项目的上下文。
3. 搜索并替换密钥、Cookie、token、邮箱和本机私有路径。
4. 检查导出内容不含二进制或大体积附件。
5. 在日期目录的 `README.md` 写工具、范围、脱敏人和导出时间。
6. 运行 `git diff --check`，再提交。
