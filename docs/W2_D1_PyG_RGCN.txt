## F2: model and training configuration

| Item | Value |
|---|---|
| embedding | `[143, 128]` |
| message passing | 3 layers; each computes per-relation mean in blocks of 84 relations, concatenates relation channels, then applies a linear map plus self projection and ReLU |
| pooling | mean + max over the concatenated three layer outputs |
| head | `768 → 768 → num_classes` |
| optimizer | Adam, `lr=0.0005`, `weight_decay=0.001` |
| scheduler | `CosineAnnealingLR`, `T_max=100` |
| batch | 64 |
| epochs | 50 |
| seeds | `0, 1, 2` |
| device | `cuda:0` (RTX 5060 Laptop GPU, sm_120) |
| selection | Immunogenicity selects checkpoint by validation AUROC; Glycosylation by validation accuracy |

Notes: the code constant `BATCH_SIZE = 256` is not the effective run; the artifact records `training.batch_size=64`. The batch-64 two-epoch memory test passed; batch 256 triggered CUDA allocation OOM, so the full run used 64. `torchdrug_installed=false`, so no bitwise TorchDrug numeric delta was measured; this implementation is structurally related, not a clone. Upstream `link_RGCN.yaml` sets `num_class: 2` while the CSV has three classes; the recompute follows the CSV.

## F2: paper target and measured result

| Task | Paper target (Table 3 RGCN row) | Measured | Interpretation |
|---|---|---|---|
| Immunogenicity | AUPRC `0.780 ± 0.006` | **`0.7748635136784087 ± 0.009111853148723878`** | paper mean lies within one measured standard deviation; no claim of full reproduction |
| Glycosylation | Macro-F1 `0.948 ± 0.004` | **`0.9377928560029268 ± 0.0038891301525018625`** | below paper by about `0.010`; no claim of full reproduction |

Additional metrics:

- Immunogenicity test AUROC: `0.9730666666666666 ± 0.0012858201014657124`; test accuracy: `0.9241379310344827 ± 0.006896551724137945`.
- Glycosylation test accuracy: `0.9613821138211381 ± 0.003520428470668453`.
- Per-seed test AUPRC: `0.7832559324152325 / 0.7651717289430979 / 0.7761628796768958`.
- Per-seed test Macro-F1: `0.9407962109575013 / 0.9333997727074045 / 0.9391825843438747`.

The difference is attributed to implementation and training-detail divergence, not a one-dimensional "0.01 is failure": the self-implemented relation layer uses blocked per-relation means, and TorchDrug's relation conv was not run locally; the model is related but not a loadable checkpoint. Ablations can later compare graph versus sequence, but this absolute gap is not yet a model-capability conclusion.
